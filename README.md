# Dog Alive

game for microcontroler project

# how to play:

1.just build

2.type command "./bin/game.exe" or just click game.exe

## controls

- w a s d to move and double tap to run(can not turn back run)
- press spacebar to attack
- j to fire arrow and hold j to change arrow type

## Slime King boss

Floor 1 is the two-phase Slime King encounter. Defeat it and wait for the NPC transformation to unlock the next floor.

Tune HP, damage, speeds, cooldowns, bounce counts, slam repeats, and beam interruption in `src/enemies/slime_king_config.h`.
See [boss settings and tests](docs/slime_king.md) for details.
